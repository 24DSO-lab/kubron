# GitOps (Argo CD)

Built in — no extra install required inside the cluster for the UI integration.

## What you get

- Applications, ApplicationSets and projects
- Sync and health status, revision, destination, last sync
- Actions: sync (with options), refresh / hard refresh, terminate operation, roll back, suspend/resume auto-sync, delete with or without cascade
- Live-vs-desired diff
- Resource graph per application
- Project roles and access
