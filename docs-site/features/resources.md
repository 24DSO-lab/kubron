# Resources & YAML editor

## Coverage

Workloads, networking, config, storage, RBAC, webhooks, leases, priority and runtime classes, plus automatically discovered CRDs.

CRDs appear with their `additionalPrinterColumns`, similar to `kubectl get`.

## Detail panels

One click away: conditions, events, owners, containers, volumes, affinity, tolerations and more.

## YAML editor

Monaco-based view / edit with a diff review step before saving. You can also create new objects from a manifest.

## Bulk actions

Select multiple objects and act on them together. One failure does not stop the rest of the batch.
