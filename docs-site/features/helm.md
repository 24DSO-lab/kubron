# Helm

## Releases

- List and inspect values, manifests and notes
- History, revision diff, rollback, uninstall

## Chart catalog

- Manage repositories (including basic auth and optional TLS skip)
- Search charts and browse versions
- OCI registries supported

## Install & upgrade

- Dry-run preview before install
- Upgrade to another chart version or only change values
- Carry over or edit values, review manifest diff first
- Update hints when a newer chart is available for an installed release
