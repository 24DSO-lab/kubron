# Releasing

Releases are cut with:

```bash
scripts/release.sh X.Y.Z
```

from the appropriate branch. Full workflow, GitHub setup and troubleshooting are described in [docs/releasing.md](https://github.com/24DSO-labs/kubron/blob/master/docs/releasing.md).

User-visible changes should be added to `CHANGELOG.md` under `[Unreleased]`.
