## What support helps us maintain

- Desktop and self-hosted Web versions.
- Kubernetes, Helm and GitOps integrations.
- Security fixes, dependency updates and release infrastructure.
- Documentation, translations, automated tests and CI.

## Public transparency

The public ledger lists confirmed transactions recorded for the published Kubron contribution addresses. It shows on-chain sender addresses and transaction hashes, not verified donor identities. The ledger data is maintained separately from wallet keys; the website never asks for or stores seed phrases or private keys.
