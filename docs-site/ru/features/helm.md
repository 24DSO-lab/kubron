# Helm

## Релизы

- Список релизов и просмотр values, manifest и notes.
- История ревизий, сравнение версий, rollback и удаление.

## Каталог чартов

- Управление репозиториями, включая basic auth и настройку пропуска проверки TLS.
- Поиск чартов и просмотр доступных версий.
- Поддержка OCI registry.

## Установка и обновление

- Предварительный dry-run перед установкой.
- Обновление до другой версии чарта или изменение только values.
- Перенос или редактирование values с предварительным просмотром diff manifest.
- Подсказки о доступных новых версиях установленных чартов.
