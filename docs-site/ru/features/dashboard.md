# Дашборд кластера

Обзор кластера помогает быстро оценить его состояние:

- количество узлов и workloads;
- сводка по capacity и хранилищу;
- общее состояние кластера;
- проблемные Pod, блокирующие факторы и предупреждения;
- Pod с потреблением ресурсов около установленных лимитов;
- узлы с небольшим запасом ресурсов;
- недавние изменения — что могло произойти перед сбоем;
- сертификаты с приближающимся сроком окончания;
- графики потребления ресурсов (если установлен дополнительный metrics stack).
