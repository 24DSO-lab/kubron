# Дашборд кластера

Дашборд помогает быстро оценить состояние активного кластера, его capacity и изменения, которые могли предшествовать инциденту.

## Состояние и ресурсы

- Готовность узлов и состояние workloads.
- Количество узлов и workloads, сводка по готовности.
- Сводка по capacity и хранилищу.
- Предупреждения и блокирующие факторы, требующие внимания.

## Сигналы для диагностики

- Проблемные Pod и причины проблем с readiness.
- Pod, приближающиеся к CPU или memory limits.
- Узлы с небольшим остатком доступных ресурсов.
- PersistentVolumeClaims в состояниях pending или lost.
- Недавние rollout Deployment, релизы Helm и синхронизации Argo CD.

Лента недавних изменений объединяет события, которые Kubron может получить из Kubernetes API и интеграций. Это полезная временная шкала для расследования, но не полный аудит всех изменений кластера.

## Сертификаты

Kubron может проверять TLS Secrets и показывать сертификаты с истёкшим или приближающимся сроком действия. Возвращаются метаданные сертификата, а не закрытый ключ. Для просмотра требуется разрешение Kubron `secrets.read` и соответствующие Kubernetes-права на чтение TLS Secrets.

## Метрики и динамика

Графики использования ресурсов и hotspots используют данные Prometheus из дополнительного стека метрик (Prometheus, kube-state-metrics и node-exporter). Без этого стека основной дашборд работает, но графики и hotspots, зависящие от метрик, не заполняются.
