# Безопасность и управление доступом

## Пользователи и роли

Встроенные роли: `admin`, `operator`, `user`. Роль `user` — только чтение: у неё нет права `secrets.read`, поэтому значения Secret, содержимое релизов Helm (values, манифест, сравнение ревизий) и сроки сертификатов ей недоступны; это право есть у `operator` и `admin`.

Разрешения детализированы: чтение, доступ к Secrets, операционные действия, запись, exec, port-forward, управление кластерами и пользователями, аудит.

## Защитные механизмы

- Хеширование паролей PBKDF2-SHA256 (600 000 итераций).
- Блокировка после неудачных попыток входа.
- Автоматический выход при бездействии с закрытием терминалов и port-forward.

## Журнал аудита

Фиксирует действия пользователей; предусмотрена ротация журнала.

## Расширения и приватность

Публичный Go API `pkg/ext` предназначен для внешних модулей, например SSO/OIDC и пользовательских хранилищ. SSO/OIDC для организаций запланирован как коммерческое дополнение.

В desktop-режиме нет телеметрии и обязательного аккаунта, kubeconfig остаётся на локальной машине.
