# Работа с ресурсами

Практическое руководство по спискам и панелям деталей, которыми вы пользуетесь каждый день. Список поддерживаемых типов ресурсов и то, что разрешает тот или иной доступ, см. в разделах [Ресурсы и YAML](/ru/features/resources) и [справочнике прав](/ru/features/security#справочник-прав).

## Выбор namespace {#choosing-namespaces}

Селектор namespace находится внизу бокового меню. Это **множественный выбор**: отметьте столько namespace, сколько нужно.

- Введите текст в поиск, чтобы сузить список. **Select shown** отмечает все подходящие namespace, а **Clear** снимает выбор.
- Если **ничего не выбрано**, Kubron показывает **все namespace**.
- Можно выбрать **до 50** namespace.
- Kubron запоминает выбор для каждого кластера. При повторном подключении он восстанавливает его или [namespace по умолчанию](/ru/features/settings#cluster-settings), если такой namespace существует.
- Списки по нескольким namespace читаются параллельно. Namespace, который вы читать не можете, помечается **No access** и не ломает весь список, так что вы по-прежнему видите всё, что вам разрешено.

Если список namespace вам вообще недоступен, селектор может остаться пустым. Задайте namespace по умолчанию в настройках кластера и см. [Диагностику](/ru/guide/troubleshooting#подключение-к-кластеру).

## Списки

Выберите тип ресурса в боковом меню, чтобы открыть его список.

| Что нужно | Как |
|---|---|
| Найти объект | Введите текст в поле **Search** над списком |
| Отсортировать | Щёлкните заголовок колонки. Повторный щелчок меняет направление |
| Показать, скрыть или переставить колонки | Откройте **Columns**. **Reset columns** возвращает набор по умолчанию. Kubron запоминает выбор для каждого типа ресурса |
| Изменить ширину колонки | Потяните её край. Двойной щелчок по краю сбрасывает ширину |
| Открыть объект | Щёлкните строку, чтобы открыть панель деталей, либо воспользуйтесь контекстным меню строки: **Show details** и **View YAML**, а также действия, подходящие для вида |
| Удалить несколько объектов | Отметьте строки (или **Select all**) и выберите **Delete selected**. Kubron просит подтверждение, а сбой на одном объекте не останавливает остальные. Доступно, только если роль разрешает удаление |
| Создать объект | **Create** (например, **Create Deployment**) открывает редактор YAML, а для видов, у которых он есть, — с заготовкой. Доступно, только если роль разрешает создание |
| Узнать, кто им управляет | Колонка **Managed by** ([подробнее](/ru/features/resources#managed-by)) |

Списки обновляются сами с интервалом, заданным в [Настройках](/ru/features/settings#application-settings). Обновление изменяет таблицу на месте, поэтому положение прокрутки и выбранные строки сохраняются.

## Панель деталей

При открытии объекта справа в окне появляется панель.

- **Properties.** Имя, namespace, возраст, labels, annotations и поля, важные для вида. **Copy name** копирует имя в буфер обмена.
- **Events.** Недавние события Kubernetes для объекта.
- **Вкладки и разделы, зависящие от вида.** Например: контейнеры, тома и метрики для Pod; ревизии для Deployment; Pod, ёмкость, выделяемые ресурсы и taint для узла; история для CronJob; правила для Role; порты и endpoint для Service; правила для Ingress; использование квоты для ResourceQuota. У объектов Argo CD и Flux есть свои вкладки, см. [GitOps](/ru/features/gitops).
- **Действия.** Масштабирование, перезапуск, откат, удаление и прочие действия, подходящие для вида. Они появляются, только если роль их разрешает. См. [Операции](/ru/features/operations).
- **Размер.** Потяните разделитель либо наведите на него фокус и используйте стрелки. **Expand panel** даёт панели больше места, **Restore panel width** возвращает вашу ширину. Kubron запоминает ширину.

### ConfigMap и Secret

Данные ConfigMap правятся по ключам: у каждого ключа свой редактор и своя кнопка **Save**.

Для раздела данных Secret нужно право `secrets.read`. Без него раздел лишь сообщает, что доступа нет. С ним каждый ключ показан **в закодированном виде** (base64); кнопка с глазом переключает ключ на **раскодированный** текст, кнопка копирования копирует его, а значение можно изменить и сохранить. Просмотр значений Secret записывается в [журнал аудита](/ru/features/administration#журнал-аудита).

## YAML

**View YAML** в контекстном меню или в панели показывает объект целиком. Редактор — Monaco, поэтому в нём работают привычные сочетания, например `Ctrl + F` для поиска.

Правка подчиняется тем же правилам, что и везде: перед сохранением показывается **diff** ваших изменений, и в кластер изменение попадает только после подтверждения. Для применения YAML нужно право `write`, а действие записывается в журнал аудита. См. [Ресурсы и YAML](/ru/features/resources).

## Если чего-то не хватает

| Симптом | Что проверить |
|---|---|
| Типа ресурса нет в боковом меню | Кластер его не обслуживает либо ваши учётные данные не могут его перечислить. Пользовательские ресурсы появляются, когда их CRD существует и вам разрешено чтение |
| Список пуст, хотя объекты есть | Выбор namespace может их исключать. Очистите выбор, чтобы увидеть все namespace |
| **No access** рядом с namespace | Kubernetes отказал в чтении для ваших учётных данных. Попросите права RBAC в этом namespace |
| Действие не предлагается | У вашей роли Kubron нет нужного права. См. [справочник прав](/ru/features/security#справочник-прав) |
| В данных Secret написано, что доступа нет | Нужно `secrets.read`, а в режиме in-cluster ServiceAccount должен иметь право читать Secret. См. [Права ServiceAccount в режиме in-cluster](/ru/server/deploy#права-serviceaccount-в-режиме-in-cluster) |
