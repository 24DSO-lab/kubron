# Baseline конфигурации

Baseline фиксирует текущую конфигурацию выбранных ресурсов. Позже вы запускаете проверку и видите, что от него отклонилось. Kubron только **читает** кластер: он не применяет baseline, не исправляет отклонения и не проверяет по расписанию.

[[toc]]

## Что поддерживается

Deployment, StatefulSet, DaemonSet, Service, Ingress, NetworkPolicy и ConfigMap. **Secret не поддерживаются и никогда не читаются**, даже если указать их явно.

Значения, которые могут быть чувствительными (данные ConfigMap, значения переменных окружения и любой текст, похожий на учётные данные), хранятся только в виде хешей с ключом. Проверка сообщает, что такое значение изменилось и к какому ключу оно относится, но не показывает само значение.

## Создание baseline

Нужно право `baseline.manage`.

1. Откройте **Baseline конфигурации** и выберите **Новый baseline**.
2. Введите название, пространства имён, при необходимости селектор меток и типы ресурсов.
3. Выберите **Предпросмотр**. Kubron прочитает кластер и покажет, что будет зафиксировано и что пришлось пропустить.
4. Введите **комментарий**, отметьте подтверждение, что текущее состояние фиксируется как есть, **включая уже существующие отклонения**, и выберите **Зафиксировать baseline**.

Если кластер изменился после предпросмотра, ничего не фиксируется: сделайте предпросмотр заново и подтвердите увиденное. Молча ничего не создаётся.

## Запуск проверки

Проверку может запустить любой, кто может читать кластер. У каждого ресурса один статус:

| Статус | Значение |
|---|---|
| Соответствует | Совпадает с активной версией |
| Изменён | Отличается; раскройте строку, чтобы увидеть поля |
| Нет в кластере | Ресурса больше нет |
| Не проверено | Сравнить не удалось (нет прав, ошибка API, неподдерживаемый тип, другие правила). Такой ресурс **никогда** не показывается как соответствующий |

У изменений есть приоритет. Источник («по данным managedFields» или «применено из Kubron») показывается только тогда, когда для него есть доказательство.

Для нагрузок под HorizontalPodAutoscaler число реплик не сравнивается. Если автомасштабирование прочитать не удалось, в результате есть соответствующая оговорка.

## Версии

**Новая версия** снова фиксирует текущее состояние; она становится активной и сохраняет исключения предыдущей. Старые версии не меняются, любую из них можно сделать активной. Версию, созданную по старым правилам сравнения, сравнить нельзя: создайте новую.

Kubron хранит не менее 20 последних версий каждого baseline и никогда не удаляет активную. Результаты проверок хранятся 90 дней.

## Исключения

Исключение убирает поле из сравнения для одного ресурса или для всех ресурсов типа. Нужен комментарий, можно задать срок. Исключения перечислены в каждом результате, поэтому скрытое отличие остаётся видимым. Просроченные исключения не применяются.
