# Управление несколькими кластерами

Добавляйте кластеры из kubeconfig и переключайтесь между ними в одном окне. Для каждого кластера можно задать:

- отображаемое имя;
- цвет и иконку;
- тег окружения: `dev`, `test`, `stage`, `prod`.

## Выбор namespace

Можно выбрать один, несколько или все namespace. Интерфейс работает с ограниченным RBAC — cluster-wide `list` не обязателен. Частичные ошибки доступа показываются явно, а не скрываются.

## Обновление данных

Shared informers поддерживают актуальность списков ресурсов и дашборда без агрессивного опроса API-сервера.
