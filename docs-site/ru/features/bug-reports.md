# Сообщить о проблеме

Кнопка **Report a problem** в шапке отправляет разработчикам Kubron отчёт об ошибке со снимком окна и несколькими техническими сведениями. Аккаунт для этого не нужен.

[[toc]]

## Отправка отчёта

1. Нажмите **Report a problem**. Kubron делает снимок окна **до** открытия диалога, поэтому на снимке видна ошибка, а не диалог.
2. Проверьте предпросмотр. Снимите флажок **Attach the screenshot**, чтобы отправить без снимка, или выберите **Retake screenshot**.
3. В поле **What happened?** опишите, что вы делали, чего ожидали и что увидели вместо этого. Описание обязательно, до 5000 символов.
4. По желанию введите **Your e-mail**, чтобы разработчики могли задать вопросы.
5. Нажмите **Send**.

Диалог ответит **The report was sent. Thank you!** либо, на компьютере без связи, **No connection: the report is saved on this computer and will be sent automatically.**

::: warning Проверьте снимок
На снимке могут быть имена, адреса, namespace или секреты, которые были на экране. Проверьте его перед отправкой или отключите вложение.
:::

## Что отправляется

| Отправляется | Не отправляется |
|---|---|
| Ваше описание и необязательный e-mail | Имена и адреса кластеров |
| Снимок, если вы его оставили (PNG до 6 МиБ) | Учётные данные |
| Версия Kubron и признак Desktop или Web | Журналы |
| Операционная система и архитектура | |
| Язык интерфейса и название открытого раздела | |
| Логин вошедшего пользователя (только Web) | |

Раскрыть детали кластера может только снимок, поэтому проверять нужно именно его.

## Куда уходит отчёт

Kubron пробует каналы доставки по порядку и останавливается на первом сработавшем:

1. **Почтовый сервер**, если он настроен. Почтовый сервер компании работает и без доступа в интернет.
2. **Приёмник проекта**, функция по адресу `https://kubron.pages.dev/api/bugreport`. Она сохраняет отчёт в **закрытом** репозитории GitHub: снимок как файл и issue со ссылкой на него. Токен доступа лежит только в секретах приёмника и никогда не попадает в Kubron.

| Версия | По умолчанию |
|---|---|
| **Desktop** | Используется приёмник проекта. В диалоге можно добавить почтовый сервер |
| **Web** | **Ничего не отправляется**, пока администратор не задаст почтовый сервер или приёмник. Без этого кнопка скрыта |

Так, в Desktop нажатие **Send** передаёт отчёт приёмнику проекта Kubron и только тогда. Сам по себе Kubron отчёты не отправляет.

## Нет связи

Если связи нет, Desktop сохраняет отчёт в папке `bugreports` в [папке данных](/ru/guide/desktop#где-kubron-хранит-данные) и отправляет его автоматически: через минуту после следующего запуска, затем каждые 15 минут. Сохранённые отчёты доступны только вам (права `0600`), Kubron хранит не более 20 самых новых и удаляет те, что старше 14 дней. Отчёт, который приёмник **отклонил**, не сохраняется, потому что повторная отправка ответ не изменит.

Если отчёты ждут отправки, диалог показывает их число (**3 report(s) are waiting to be sent**) и кнопку **Save as archive**. Она записывает один `.zip` с папкой на каждый отчёт (текст, снимок и сведения) и показывает его в файловом менеджере, чтобы вы могли передать его разработчикам любым способом. Отчёты остаются в очереди и всё равно уйдут, когда появится связь.

## Почтовый сервер (Desktop)

Откройте **Mail server settings** в диалоге.

| Поле | Примечания |
|---|---|
| **Server**, **Port** | По умолчанию порт 587 (465 для TLS, 25 без шифрования) |
| **Connection** | **STARTTLS**, **TLS (SSL)** или **No encryption (this machine only)** для сервера на этом же компьютере |
| **User**, **Password** | Данные входа. Для пользователя нужен пароль. Для Gmail используйте [пароль приложения](https://support.google.com/accounts/answer/185833), а не пароль учётной записи |
| **From address** | По умолчанию совпадает с пользователем. Gmail требует вошедшую учётную запись |
| **Send reports to** | Получатель |

Настройки сохраняются в `bugreport.json` в папке данных (права `0600`), а пароль шифруется мастер-ключом Kubron. Если ключ недоступен, Kubron сообщает, что сохранить настройки здесь нельзя, и предлагает воспользоваться переменными окружения. Переменные `KUBRON_BUGREPORT_SMTP_*` тоже читаются; **сохранённые настройки приоритетнее**. **Remove saved settings** возвращает к переменным.

::: warning Укажите получателя
Если вы настроили почтовый сервер и не задали получателя, отчёты уйдут в **собственный почтовый ящик проекта**, а не вам. Если отчёты должны оставаться внутри вашей организации, всегда задавайте **Send reports to** (`KUBRON_BUGREPORT_SMTP_TO`).
:::

## Web: для администраторов

Администратор задаёт почтовый сервер или приёмник переменными окружения; пользователи не могут их прочитать или изменить. Кнопка появляется, когда `KUBRON_BUGREPORT_SMTP_HOST` или `KUBRON_BUGREPORT_RELAY_URL` заданы корректно. Серверу без доступа в интернет следует использовать почтовый сервер вашей организации. Если заданы оба канала, сначала пробуется почта. При `NetworkPolicy` разрешите исходящий трафик к почтовому серверу (его порт SMTP) или HTTPS к приёмнику. См. [Развёртывание в Docker и Kubernetes](/ru/server/deploy#bug-reports) и [справочник по конфигурации](/ru/server/configuration).

`KUBRON_BUGREPORT_RELAY_URL=off` явно отключает приёмник.

## Ограничения и аудит

- Один отчёт на пользователя раз в **30 секунд**. Web-сервер ещё и останавливается на **30 отчётах в час** суммарно.
- Приёмник проекта принимает **10 отчётов в час с одного адреса** и **200 в сутки** суммарно.
- Каждый отправленный отчёт записывается в [журнал аудита](/ru/features/administration#журнал-аудита) как **bugreport.submit**, **без текста**.

## Сообщения

| Сообщение | Значение |
|---|---|
| **The mail server is not set up yet. Fill in the settings below to send reports.** | Нет доступного канала доставки. В Desktop так бывает только при отключённом приёмнике (`KUBRON_BUGREPORT_RELAY_URL=off`) и незаданном почтовом сервере |
| **The mail server for reports is not set up. Ask the administrator to set KUBRON_BUGREPORT_SMTP_\*.** | Web: администратор должен всё настроить |
| **The screenshot could not be taken. The report can be sent without it.** | Отправьте без снимка |
| **No connection: the report is saved on this computer and will be sent automatically.** | Desktop поставил отчёт в очередь |
