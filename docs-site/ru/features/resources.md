# Ресурсы и YAML-редактор

## Поддерживаемые ресурсы

Kubron отображает workloads, сетевые и конфигурационные ресурсы, хранилища, RBAC, webhooks, leases, priority и runtime classes, а также автоматически обнаруживает CRD.

CRD отображаются с колонками `additionalPrinterColumns`, аналогично `kubectl get`.

## Панели подробностей

В один клик доступны conditions, events, owners, containers, volumes, affinity, tolerations и другие сведения.

## YAML-редактор

Редактор на базе Monaco позволяет просматривать и изменять YAML. Перед сохранением можно проверить diff. Также можно создавать новые объекты из manifest.

## Массовые действия

Выберите несколько объектов и выполните действие сразу для всей группы. Ошибка одного объекта не прерывает обработку остальных.
