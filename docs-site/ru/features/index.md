# Возможности Kubron

Kubron — рабочее пространство для повседневных операций с Kubernetes: наблюдения за кластерами, диагностики и управления ресурсами в desktop и web.

## Кластеры и дашборд

- Несколько кластеров с именами, цветами, иконками и тегами окружений.
- Выбор одного, нескольких или всех namespace; поддержка ограниченного RBAC.
- Обновление данных через shared informers.
- Состояние узлов, workloads, capacity и хранилища.
- Проблемные Pod, блокирующие факторы, узлы с низким запасом ресурсов.
- Недавние изменения и сертификаты с истекающим сроком.

## Ресурсы и операции

- Встроенные типы Kubernetes и автоматически обнаруживаемые CRD.
- Панели подробностей, YAML-редактор Monaco с предварительным diff.
- Массовые действия и горячие клавиши.
- Логи Pod, exec, port-forward и eviction.
- Масштабирование и перезапуск Deployments, история ревизий и rollback.
- Cordon, drain и shell для узлов.
- Необязательные графики метрик.

## Helm и GitOps

- Каталог Helm-чартов, репозитории и OCI registry.
- Установка и обновление с dry-run и diff, история релизов и rollback.
- Встроенная интеграция Argo CD: Applications, ApplicationSets, Projects, sync, diff и граф ресурсов.

## Безопасность

- Локальные пользователи с ролями `admin`, `operator`, `user`.
- Детальные разрешения, защита паролей, блокировка входа и автоматический выход.
- Журнал аудита.
- Публичный API расширений `pkg/ext`.
- Нет телеметрии; в desktop-режиме не нужен обязательный аккаунт.
