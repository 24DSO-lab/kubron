# Настройки и настройки кластера

В Kubron два вида настроек: несколько общих для приложения (язык, обновление, метрики) и отдельный диалог для каждого кластера (имя, kubeconfig, namespace по умолчанию, внешний вид и другое).

[[toc]]

## Настройки приложения {#application-settings}

Откройте **Settings** в боковом меню.

| Настройка | Что делает |
|---|---|
| **Language** | Язык интерфейса: English, Русский или 中文. Выбор запоминается на этом устройстве, а при первом запуске берётся язык системы |
| **Auto-refresh** | Как часто обновляются списки ресурсов, в секундах. По умолчанию 10. Обновить списки вручную можно всегда |
| **Metrics stack** | Устанавливает, проверяет и удаляет необязательный стек Prometheus. См. [Стек метрик и графики](/ru/features/metrics) |

::: warning Отключение автообновления
Значение `0` отключает автообновление, и списки обновляются только вручную. В текущей версии сохранённый `0` при следующем запуске Kubron заменяется значением по умолчанию — 10 секунд.
:::

## Настройки кластера {#cluster-settings}

Откройте меню кластера в верхней панели и выберите **Edit** либо **Add** для нового кластера. Диалог один и тот же.

| Поле | Примечания |
|---|---|
| **Name** | Показывается в переключателе кластеров и в заголовке |
| **Kubeconfig** | Kubron хранит копию в собственной папке. Можно **заменить файлом** или **править текст** (текст содержит учётные данные, не показывайте экран посторонним). В Web-версии значения секретов в тексте скрыты и сохраняются как есть; изменить значение можно через **Replace secret**. **Revert** отбрасывает правки |
| **Context** | Контекст kubeconfig. Контекст по умолчанию помечен |
| **Default namespace** | Выбирается автоматически при подключении. Строчные латинские буквы, цифры и дефисы, не более 63 символов. Если оставить пустым, начинается со всех namespace |
| **Test connection** | Показывает версию Kubernetes и задержку либо причину сбоя. См. ниже |
| **Environment** | Not set, Dev, Test, Stage или Prod. Пока открыт кластер **Prod**, в заголовке показывается красная линия, чтобы его нельзя было принять за другой |
| **Icon** и **Color** | Монограмма из имени или значок, готовый или свой цвет |
| **Argo CD address** | Опубликованный адрес Argo CD (например, Ingress): `http` или `https` без учётных данных, query и fragment. Если задан, Kubron открывает его вместо проброса порта. Если пусто, Argo CD открывается через API кластера |
| **Delete cluster** | Удаляет кластер и его kubeconfig из Kubron после подтверждения. Исходный kubeconfig не затрагивается |

### Только в Web-версии

| Поле | Примечания |
|---|---|
| **Team** (владелец) | Команда, которой принадлежит кластер. Её участники получают доступ согласно своим ролям. Чтобы добавить кластер, нужно быть администратором команды |
| **Добавить кластер, в котором работает Kubron** | Использует ServiceAccount сервера, поэтому все, у кого есть роль в команде, получают права этого ServiceAccount. См. [Права ServiceAccount в режиме in-cluster](/ru/server/deploy#права-serviceaccount-в-режиме-in-cluster) |
| **Shared team account** | Включено: вся команда подключается одной учётной записью, а администратор кластера входит один раз. Выключено: каждый входит своей |
| **Forget the shared sign-in** | Забывает сохранённый общий вход. При следующем подключении администратора кластера попросят войти снова. Смена настройки учётной записи делает то же для всех |

Если ваш доступ к кластеру отозван, Kubron сообщит об этом и закроет его терминалы, потоки логов и port-forward.

### Проверка подключения

| Результат | Значение |
|---|---|
| **Reachable** с версией и задержкой | Адрес и учётные данные работают |
| **Could not connect** с причиной | Сбой адреса, TLS или учётных данных. См. [Диагностику](/ru/guide/troubleshooting#подключение-к-кластеру) |
| Предупреждение **no permission to read namespaces** | API-сервер ответил, но список namespace вам недоступен. Многие разделы всё равно работают; выбирайте namespace сами в селекторе. См. [Работа с ресурсами](/ru/features/working-with-resources#choosing-namespaces) |
| Предупреждение о том, что kubeconfig входит через плагин или провайдера идентификации | Адрес доступен. Сам вход проверяется при подключении |

### Состояние кластера

В панели кластеров показано состояние каждого кластера: **Available**, **Unreachable**, **Credentials rejected**, **Misconfigured** или **Not checked**. В Web-версии сервер проверяет кластеры в фоне (`KUBRON_CLUSTER_CHECK_INTERVAL`, по умолчанию 30 секунд).
