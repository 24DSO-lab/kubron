# Начало работы

Kubron — Kubernetes Operations Workspace в двух версиях. Обе версии предоставляют интерфейс Kubron для работы с кластерами, workloads, Helm и GitOps. Выберите подходящий способ использования:

Впервые здесь? Сначала прочитайте [Что такое Kubron](/ru/guide/what-is-kubron).

## Выберите версию

| | Desktop | Web |
| --- | --- | --- |
| **Как используется** | Нативное приложение на вашем компьютере | Собственное web-приложение в браузере |
| **Развёртывание** | Установка и запуск локально, без отдельного сервера | Вы или ваша команда разворачиваете и обслуживаете сервер Kubron |
| **Типичный сценарий** | Индивидуальная работа | Совместная работа нескольких пользователей |
| **Учётные записи и доступ** | Учётная запись не обязательна | Локальные учётные записи и роли |
| **Аудит и конфигурация** | Kubeconfig остаётся на вашем компьютере | Журнал аудита и централизованное хранение конфигурации |
| **Подходит, если** | Вы работаете самостоятельно и не хотите обслуживать сервер | Команде нужен общий интерфейс в браузере и централизованное управление |

Выбирайте **Desktop**, если в основном работаете самостоятельно и хотите быстро начать работу локально.

Выбирайте **Web**, если нескольким людям нужен доступ к общей среде Kubron через браузер, с учётными записями, ролями и журналом аудита.

## Desktop

Запускайте Kubron как desktop-приложение на своём компьютере. Это самый простой вариант для индивидуальной работы: не нужно разворачивать сервер, нет обязательной учётной записи и телеметрии. Kubeconfig остаётся на вашем компьютере.

[Скачать и настроить Desktop](/ru/guide/desktop).

## Web

Разверните Kubron как собственное web-приложение и открывайте его в браузере. Эта версия предназначена для совместной работы: локальные учётные записи, роли, журнал аудита и централизованное хранение конфигурации.

Сервер Kubron разворачиваете и обслуживаете вы или ваша команда. Это не облачный SaaS-сервис, предоставляемый Kubron.

[Начать работу с Web](/ru/guide/web).
