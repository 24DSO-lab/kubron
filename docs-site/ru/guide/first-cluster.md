# Первый кластер

1. Откройте **Settings → Clusters** или переключатель кластеров в верхней панели.
2. Нажмите **Add cluster**.
3. Выберите kubeconfig-файл или вставьте содержимое конфигурации контекста.
4. Укажите имя кластера; при необходимости задайте цвет, иконку и тег окружения: `dev`, `test`, `stage` или `prod`.
5. При необходимости ограничьте доступный набор namespace.

Kubron поддерживает ограниченный RBAC: для выбора namespace не требуется cluster-wide `list`. Частичные ошибки доступа отображаются явно.

## Несколько кластеров

Можно добавить несколько кластеров и переключаться между ними в одном окне. У каждого кластера свои фильтры namespace и состояние представления.
