# Web-версия

Web-версия запускает Kubron как собственный сервер и предоставляет интерфейс в браузере. Она предназначена для команд и общих сред, где нужны учётные записи пользователей, роли, разрешения и журнал аудита.

**Модель размещения:** Kubron не предоставляет готовый облачный SaaS-сервис. Сервер разворачивает и обслуживает ваша команда в собственной инфраструктуре.

## Два режима {#modes}

`kubron-server` работает в одном из двух режимов. Не каждый сервер — командный.

| | Личный режим | Сервисный режим |
|---|---|---|
| Хранилище | Файлы (`~/.kubron` или `KUBRON_DATA_DIR`) | PostgreSQL |
| Типичное использование | Один человек, знакомство, прослушивание loopback | Команда или общая среда |
| Учётные записи | Локальные пользователи и роли | Локальные пользователи, роли и **команды** |
| Несколько реплик (высокая доступность) | Нет | Да |
| Ключ шифрования `KUBRON_SECRET_KEY` | Не нужен | Нужен всегда, когда используется база |
| Токен первичной настройки для первого администратора | На loopback не нужен | Нужен по сети |
| Как запускается | `kubron-server --listen 127.0.0.1:8080` | С `KUBRON_DATABASE_URL` либо на не-loopback адресе |

::: warning Для командной работы нужен PostgreSQL
Команды, изоляция команд и несколько реплик требуют PostgreSQL (сервисный режим). Файловое хранилище рассчитано на одного человека и на знакомство с Kubron.
:::

## Выберите способ запуска

### Локальное знакомство

Для локальной оценки сервер может использовать файловое хранилище и слушать только loopback-интерфейс:

[Быстрый запуск Web локально](/ru/server/quick-start). Он включает запуск одного пользователя из исходников и многопользовательскую пробу в Docker Compose с PostgreSQL.

Этот вариант предназначен для знакомства с продуктом, а не для production.

### Развёртывание для команды

Для совместной работы используйте опубликованный контейнерный образ или Helm chart. Production-развёртывание требует PostgreSQL, постоянного ключа шифрования, TLS на доверенном reverse proxy или ingress и соответствующих сетевых ограничений.

[Инструкция по развёртыванию в Docker и Kubernetes](/ru/server/deploy).

## Чем Web отличается от Desktop?

- Пользователи открывают Kubron в браузере, а не запускают desktop-приложение.
- Сервер управляет учётными записями, ролями, разрешениями, сессиями и журналом аудита.
- PostgreSQL хранит общее состояние приложения; kubeconfig и GitOps credentials шифруются при хранении.
- При использовании PostgreSQL сервер можно запускать в нескольких репликах.

Перед публикацией сервиса изучите [обзор Web-версии](/ru/server/) и [требования безопасности](/ru/features/security).

## Подключить кластер

После входа добавьте кластер через интерфейс Kubron. Сервер не может читать файлы с вашего компьютера и никогда не запускает команды из kubeconfig; поддерживаемые виды учётных данных описаны в разделе [Подключение к Kubernetes](/ru/features/cluster-auth#web). Доступные операции определяются разрешениями пользователя и Kubernetes RBAC, настроенным на сервере.
