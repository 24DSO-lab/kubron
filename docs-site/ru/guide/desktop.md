# Desktop-версия

Desktop-версия запускает Kubron непосредственно на вашем компьютере. Это самый быстрый способ начать работу с Kubernetes без развёртывания и обслуживания собственного сервера.

## Скачать

Откройте [GitHub Releases](https://github.com/24DSO-labs/kubron/releases) и скачайте сборку для своей операционной системы:

| Платформа | Пакет |
|---|---|
| Windows (x64) | `Kubron_<version>_windows-amd64.zip` |
| Linux (x64) | `Kubron_<version>_linux-amd64.tar.gz` |
| Linux (Debian/Ubuntu) | `kubron_<version>_amd64.deb` |
| macOS (Apple Silicon + Intel) | `Kubron_<version>_macos-universal.zip` |

Контрольные суммы опубликованы в `SHA256SUMS.txt`; для артефактов релиза также доступны аттестации сборки.

## Установка и запуск

1. Скачайте пакет для своей операционной системы.
2. Распакуйте архив или установите пакет.
3. Запустите Kubron.
4. При первом запуске импортируйте kubeconfig-файл или используйте стандартный `~/.kube/config`.

В Linux приложению нужны GTK 3 и WebKitGTK 4.1. Пакеты Debian автоматически устанавливают runtime-зависимости. Названия пакетов и инструкции по сборке из исходников приведены в разделе [Подробности установки](/ru/guide/installation).

::: tip Предупреждения системы
Сборки пока не подписаны кодовой подписью. Windows SmartScreen может показать предупреждение. Если macOS блокирует запуск, откройте контекстное меню приложения в Finder и выберите **Open**.
:::

## Подключить кластер

После запуска добавьте кластер через **Settings → Clusters** или переключатель кластеров. См. инструкцию [Добавить первый кластер](/ru/guide/first-cluster).
