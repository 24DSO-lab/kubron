# Desktop-версия

Desktop-версия запускает Kubron непосредственно на вашем компьютере. Это самый быстрый способ начать работу с Kubernetes без развёртывания и обслуживания собственного сервера. Руководство проведёт вас от скачанного файла до работающего Kubron в **Windows**, **macOS** или **Linux**.

Сначала проверьте [системные требования](/ru/guide/installation#системные-требования) и [проверьте загрузку](/ru/guide/installation#проверка-загрузки) перед запуском.

## Скачать

Откройте [GitHub Releases](https://github.com/24DSO-lab/kubron/releases) и скачайте сборку для своей операционной системы:

| Платформа | Пакет |
|---|---|
| Windows (x64) | `Kubron_v<версия>_windows-amd64.zip` |
| macOS (Apple Silicon + Intel) | `Kubron_v<версия>_macos-universal.zip` |
| Linux (x64) | `Kubron_v<версия>_linux-amd64.tar.gz` |
| Linux (Debian/Ubuntu) | `kubron_<версия>_amd64.deb` |

Контрольные суммы лежат в `SHA256SUMS.txt`, к файлам релиза прилагается provenance сборки. См. [Проверка загрузки](/ru/guide/installation#проверка-загрузки).

## Windows

### Требования

- Windows 10 или 11, 64-разрядная.
- Microsoft Edge WebView2 Runtime. Он входит в Windows 11 и в актуальную Windows 10. Если его нет, приложение не сможет отрисовать окно: установите *Evergreen Runtime* с сайта [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/) и запустите Kubron снова.

### Шаги

1. Скачайте `Kubron_v<версия>_windows-amd64.zip` со страницы [Releases](https://github.com/24DSO-lab/kubron/releases).
2. *(Рекомендуется)* Проверьте файл: [контрольная сумма и происхождение](/ru/guide/installation#проверка-загрузки).
3. Щёлкните zip правой кнопкой, откройте **Свойства** и, если есть такая опция, отметьте **Разблокировать**. Или выполните в PowerShell:

   ```powershell
   Unblock-File .\Kubron_v1.1.0_windows-amd64.zip
   ```

4. Распакуйте архив. В нём один файл, `Kubron.exe`. Поместите его в удобную папку, например `C:\Tools\Kubron\` или `%LOCALAPPDATA%\Programs\Kubron\`.
5. Дважды щёлкните `Kubron.exe`.

   Если появится **Windows защитила ваш компьютер** (SmartScreen), нажмите **Подробнее → Выполнить в любом случае**. Для сборок, ещё не подписанных сертификатом, это ожидаемо.

6. *(Необязательно)* Закрепите `Kubron.exe` в меню «Пуск» или создайте ярлык на рабочем столе.

Установщика нет, в реестр ничего не пишется. Данные Kubron хранит в `%USERPROFILE%\.kubron`.

## macOS

### Требования

- Mac на Apple Silicon или Intel. Загрузка — одна универсальная сборка.

### Шаги

1. Скачайте `Kubron_v<версия>_macos-universal.zip`.
2. *(Рекомендуется)* Проверьте файл: [контрольная сумма и происхождение](/ru/guide/installation#проверка-загрузки).
3. Дважды щёлкните zip, чтобы получить `Kubron.app`, и перетащите его в **Программы** (Applications).
4. Первый запуск будет заблокирован, потому что приложение пока не нотаризовано. Сделайте **одно** из следующего:

   - В Finder **щёлкните правой кнопкой** (или Control-клик) по `Kubron.app` → **Открыть** → **Открыть** в диалоге.
   - Или снимите флаг карантина в Терминале:

     ```bash
     xattr -dr com.apple.quarantine /Applications/Kubron.app
     ```

   - Или, если macOS пишет, что приложение «невозможно открыть», зайдите в **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение про Kubron и нажмите **Всё равно открыть**.

5. После первого успешного запуска macOS запомнит ваш выбор, и Kubron будет открываться как обычно.

Данные Kubron хранит в `~/.kubron`.

## Linux

Kubron нужны **GTK 3** и **WebKitGTK 4.1**. Выберите способ установки для вашего дистрибутива.

### Debian, Ubuntu и производные (`.deb`)

Пакет объявляет свои зависимости (`libgtk-3-0`, `libwebkit2gtk-4.1-0`), поэтому `apt` установит всё необходимое.

```bash
sudo apt install ./kubron_1.1.0_amd64.deb
```

Укажите путь к скачанному файлу. Установка через `apt install ./file.deb` (а не `dpkg -i`) сама разрешает зависимости.

Пакет устанавливает:

| Путь | Назначение |
|---|---|
| `/usr/bin/kubron` | Приложение |
| `/usr/share/applications/kubron.desktop` | Пункт меню приложений (категория *Development*) |
| `/usr/share/icons/hicolor/512x512/apps/kubron.png` | Иконка |
| `/usr/share/doc/kubron/` | `LICENSE` и `NOTICE` |

Запустите из меню приложений или командой `kubron` в терминале.

Для обновления установите новый `.deb` тем же способом. Данные в `~/.kubron` не затрагиваются. Удаление:

```bash
sudo apt remove kubron
```

### Другие дистрибутивы (`.tar.gz`)

1. Установите библиотеки времени выполнения:

   ::: code-group

   ```bash [Fedora / RHEL]
   sudo dnf install gtk3 webkit2gtk4.1
   ```

   ```bash [Arch / Manjaro]
   sudo pacman -S gtk3 webkit2gtk-4.1
   ```

   ```bash [openSUSE]
   sudo zypper install libgtk-3-0 libwebkit2gtk-4_1-0
   ```

   ```bash [Debian / Ubuntu]
   sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
   ```

   :::

   Названия пакетов немного различаются между дистрибутивами и версиями. Если имя не найдено, поищите в менеджере пакетов `webkit2gtk` и выберите вариант **4.1**.

2. Распакуйте архив. В нём один исполняемый файл `Kubron`:

   ```bash
   tar -xzf Kubron_v1.1.0_linux-amd64.tar.gz
   chmod +x Kubron
   ./Kubron
   ```

3. *(Необязательно)* Установите для своего пользователя, чтобы файл был в `PATH`:

   ```bash
   mkdir -p ~/.local/bin
   install -m 0755 Kubron ~/.local/bin/kubron
   ```

4. *(Необязательно)* Добавьте пункт меню. Создайте `~/.local/share/applications/kubron.desktop`:

   ```ini
   [Desktop Entry]
   Type=Application
   Name=Kubron
   GenericName=Kubernetes Operations Workspace
   Comment=Workspace for Kubernetes operations across clusters
   Exec=%h/.local/bin/kubron
   Terminal=false
   Categories=Development;System;
   Keywords=kubernetes;k8s;cluster;kubectl;
   StartupWMClass=Kubron
   ```

   Некоторые окружения рабочего стола не раскрывают `%h`. Если пункт не запускается, пропишите абсолютный путь, например `/home/alex/.local/bin/kubron`.

Для обновления замените исполняемый файл новым. Для удаления удалите его и файл `.desktop`.

## Первый запуск

При первом старте пользователей ещё нет, поэтому Kubron просит создать локального администратора.

1. Открывается экран **Welcome to Kubron**. При желании выберите язык интерфейса в углу; по умолчанию он следует языку системы.
2. Введите **имя пользователя**: 3–32 символа, латинские буквы, цифры, `.`, `-` и `_`.
3. Введите **пароль** не короче 8 символов и подтвердите его.
4. Нажмите **Create administrator**. Вы вошли.

После этого при запуске Kubron показывает форму входа. Учётная запись существует только на вашем компьютере: это не онлайн-аккаунт, и ничего никуда не отправляется.

::: tip Автовыход
Для безопасности Kubron завершает сеанс после периода бездействия (по умолчанию 15 минут; администратор может изменить срок или отключить автовыход). При этом закрываются и открытые терминалы, port-forward и потоки логов.
:::

Дальше: [добавьте первый кластер](/ru/guide/first-cluster).

## Где Kubron хранит данные

Всё лежит в одной папке в вашем домашнем каталоге:

| ОС | Расположение |
|---|---|
| Linux, macOS | `~/.kubron` |
| Windows | `%USERPROFILE%\.kubron` |

| Элемент | Примечания |
|---|---|
| `config.json` | Настройки интерфейса, например тема и последний активный кластер |
| `users.json` | Локальные учётные записи |
| `clusters/` | Kubeconfig добавленных кластеров, а также их имена, цвета и теги |

Kubron создаёт папку так, чтобы войти в неё мог только ваш пользователь (`0700`), и записывает конфигурацию с правами только для владельца. Исходный kubeconfig (например, `~/.kube/config`) не изменяется.

**Резервная копия:** скопируйте папку целиком при закрытом Kubron. **Сброс:** закройте Kubron и удалите папку; следующий запуск будет как первая установка.

## Обновление и удаление

| | Windows | macOS | Linux `.deb` | Linux `.tar.gz` |
|---|---|---|---|---|
| **Обновление** | Заменить `Kubron.exe` | Заменить `Kubron.app` в Программах | `sudo apt install ./new.deb` | Заменить файл `Kubron` |
| **Удаление** | Удалить `Kubron.exe` | Перетащить `Kubron.app` в Корзину | `sudo apt remove kubron` | Удалить файл |

Кластеры и учётная запись остаются в `~/.kubron` при обновлениях. Удаляйте эту папку, только если хотите стереть и свои данные. Перед переходом между мажорными версиями прочитайте [журнал изменений](https://github.com/24DSO-lab/kubron/blob/master/CHANGELOG.md).

## Если что-то не работает

### Windows: «Windows защитила ваш компьютер»
SmartScreen предупреждает о приложениях без сертификата подписи кода. Нажмите **Подробнее → Выполнить в любом случае**. Если нужна уверенность, сначала выполните [проверку суммы и происхождения](/ru/guide/installation#проверка-загрузки).

### Windows: окно пустое или приложение сразу закрывается
Установите или восстановите **WebView2 Runtime** (см. [Требования](#требования)). Убедитесь также, что файл распакован из zip: запуск `Kubron.exe` из окна просмотра архива может не сработать.

### macOS: «Kubron повреждён» или «невозможно открыть, так как разработчик не может быть проверен»
Это реакция Gatekeeper на флаг карантина. Используйте способ с правой кнопкой **Открыть** или выполните `xattr -dr com.apple.quarantine /Applications/Kubron.app`, как показано выше.

### Linux: ошибка про `libwebkit2gtk-4.1.so.0` или `libgtk-3.so.0`
Не хватает библиотеки времени выполнения. Установите пакеты из шагов выше, затем проверьте, чего ещё нет:

```bash
ldd ./Kubron | grep "not found"
```

Если в системе есть только `libwebkit2gtk-4.0` (старые дистрибутивы), ваш дистрибутив слишком старый для текущих сборок. Используйте более новую версию дистрибутива или [соберите из исходников](/ru/guide/build-from-source).

### Linux: окно открывается, но пустое или с артефактами
Некоторые сочетания GPU и Wayland ломают отрисовку WebKitGTK. Попробуйте запустить Kubron с отключённым DMA-BUF-рендерером:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 kubron
```

Если помогло, добавьте это в строку `Exec=` вашего `.desktop`-файла: `env WEBKIT_DISABLE_DMABUF_RENDERER=1 kubron`.

### Кластер не подключается, а kubeconfig использует `exec`
В Azure AKS (`kubelogin`), AWS EKS и Google GKE Kubron входит сам. Для любого другого `exec`-плагина Kubron показывает команду, аргументы и имена переменных окружения и просит подтвердить локальный запуск. Плагин должен быть установлен и находиться в `PATH`, который видит приложение. Программы, запущенные из Dock macOS или из меню Linux, не всегда наследуют `PATH` вашей оболочки: запустите Kubron из терминала для проверки либо пропишите в kubeconfig полный путь к команде плагина. Выбор **Always for this kubeconfig** запоминается в файле `exec-trust.json` в [папке данных](#где-kubron-хранит-данные); удалите файл, чтобы забыть все решения. См. [Подключение к Kubernetes](/ru/features/cluster-auth).

### «Sign-in unavailable»: файл пользователей не удалось прочитать
Kubron не смог прочитать `~/.kubron/users.json` и остаётся закрытым, чтобы не рисковать вашими данными. Восстановите файл из резервной копии. См. [Где Kubron хранит данные](#где-kubron-хранит-данные).
