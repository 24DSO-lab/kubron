# Горячие клавиши

В Kubron немного горячих клавиш. На этой странице перечислены те, что есть в текущей версии.

## Переход к разделу

На **обзоре** кластера (дашборде) эти сочетания открывают нужный раздел:

| Сочетание | Действие |
|---|---|
| `Alt + P` | Перейти к Pods |
| `Alt + D` | Перейти к Deployments |
| `Alt + N` | Перейти к Nodes |
| `Alt + E` | Перейти к Events |
| `Alt + S` | Открыть Settings |

Примечания:

- Сочетания работают, пока открыт обзор. Из другого раздела пользуйтесь боковым меню или сначала вернитесь на обзор.
- Нажимайте только `Alt` и букву. Сочетания, в которые входят ещё `Ctrl`, `Shift` или `Cmd`, игнорируются.
- Они игнорируются, пока вы печатаете в текстовом поле, поиске или редакторе, поэтому не мешают вводу.
- В macOS `Alt` — это клавиша `Option`.

## Диалоги и меню

| Сочетание | Где | Действие |
|---|---|---|
| `Esc` | Диалоги, контекстные меню, меню кластера, выбор колонок | Закрыть. Диалоги добавления и правки кластера игнорируют `Esc`, пока идёт сохранение |
| `Ctrl + Enter` (`Cmd + Enter` в macOS) | Диалоги добавления и правки кластера | Отправить форму |
| `Tab` | Диалог входа в кластер | Переход между полями; фокус остаётся внутри диалога |

## Изменение размера панелей

У боковой панели и панели деталей ресурса есть перетаскиваемый разделитель. Когда разделитель в фокусе, стрелки меняют размер:

| Сочетание | Действие |
|---|---|
| `→` / `←` | Боковая панель: шире / уже |
| `←` / `→` | Панель деталей (справа): шире / уже |
| `Shift` + стрелка | То же, шаг в четыре раза больше |

Kubron запоминает выбранную ширину.

## Редактор YAML и терминал

Редактор YAML — это Monaco, а терминал — xterm, поэтому внутри них действуют их собственные стандартные сочетания, например `Ctrl + F` для поиска в редакторе. Эти сочетания предоставляют сами компоненты, они не специфичны для Kubron.

Новые сочетания будут добавляться в документацию по мере появления.
