# Расширение Kubron

Kubron предоставляет публичный Go API в `pkg/ext` для внешних модулей — например, SSO/OIDC и пользовательских хранилищ.

В open core остаются локальные пользователи, роли, журнал аудита и аварийный доступ администратора. SSO/OIDC для организаций запланирован как коммерческое дополнение.

См. документацию пакета и примеры в каталоге `examples/ext-authenticator` основного репозитория.
