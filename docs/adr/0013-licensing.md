# ADR-0013: Лицензия: Apache-2.0

- Статус: принято
- Дата: 2026-10-25
- Связано: Задачи 0.9, 0.10

## Контекст

Проект open source. Вход через SSO/OIDC нужен организациям; его реализация живёт в этом же репозитории.

## Решение

Весь код проекта, включая SSO/OIDC, — Apache-2.0 в этом репозитории. Локальные пользователи, роли, аудит и аварийный админ входят в ядро. SSO подключается через публичные интерфейсы (`pkg/ext`), чтобы вход можно было расширять и заменять без правок ядра. DCO для внешних вкладов.

## Рассмотренные альтернативы

AGPL-3.0 + CLA (отпугивает компании); source-available (не open source).

## Последствия

Риск облачного форка ядра; перед публичным релизом показать лицензию юристу; проверить название/торговую марку.

Редакция 2026-11-06: SSO/OIDC реализуется в основном репозитории. Прежняя редакция (отдельный модуль) сохранена в истории git.
