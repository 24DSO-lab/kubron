# Журнал решений

Здесь записываются решения, принятые по ходу работы **без отдельного обсуждения**, чтобы потом можно было разобрать,
кто и почему так решил. Архитектурные решения, требующие утверждения команды, по-прежнему оформляются как ADR
(`docs/adr`); сюда попадают меньшие и операционные.

Каждая запись: контекст, варианты, решение, обоснование, последствия, как отменить, статус. Поле **Принял** называет
того, кто принял решение, и по чьему поручению; статус **«ждёт ревью»** значит, что человек решение не проверял.
