## Решение по внешнему Argo CD URL

Владелец выбрал предупреждение перед переходом на внешний адрес вместо организационного allowlist.

Реализация:
- перед открытием `argoUrl` UI показывает hostname назначения;
- пользователь должен явно подтвердить переход;
- отмена не открывает внешний адрес;
- для внутреннего Argo CD через port-forward подтверждение не показывается;
- текст предупреждения локализован на английский, русский и китайский.

Статус реализации: PR #111 (`feat/confirm-external-argo-url`) влит в `refactor`; CI успешен. Находка 10 закрыта в `docs/security-review.md`.

## Оставшиеся продуктовые задачи

- SSO/OIDC для входа в само приложение — отдельная фаза, не блокер базовой веб-версии.
- Хеширование паролей: Argon2id v=19, m=19 MiB, t=2, p=1. Существующие PBKDF2-хеши проверяются и автоматически обновляются до Argon2id при успешном входе; принудительный сброс паролей не требуется.
