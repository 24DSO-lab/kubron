## Цель

Пользователь и администратор получают актуальную документацию по второй итерации: новые виды цели, права, метрики этапа B, пересчёт корреляции, карта. RBAC и чарт покрывают чтение новых видов. Ты пишешь по `contracts.md` и ADR, а не по чужому коду — поэтому не ждёшь никого.

## Твои файлы (создаёшь и правишь только их)

- `docs/intelligence.md`, `docs/intelligence-operations.md`, `docs/intelligence-rule-improvement.md`, `docs/metrics.md`, `docs/i18n.md` (если затрагивается) — новые разделы: виды цели и цепочки, карта, метрики этапа B, пересчёт корреляции.
- `docs/intelligence-contracts.md` — не менять (справочник первой итерации).
- `docs-site/**` — те же темы для сайта, если разделы Intelligence там есть.
- `deploy/helm/kubron/**` (шаблоны RBAC технической учётной записи и `values.yaml` + комментарии), `deploy/**` — сверка и дополнение прав **только `get`/`list`**: `ingresses`, `ingressclasses` (`networking.k8s.io`), `horizontalpodautoscalers` (`autoscaling`), `configmaps`, `statefulsets`, `jobs`, `cronjobs`, `controllerrevisions` НЕ нужны; Secret не добавлять; `helm template` рендерится без ошибок, есть/обновлён тест чарта, если он существует.
- `CHANGELOG.md` — раздел «Вторая итерация Kubron Intelligence» из строк для CHANGELOG в PR (черновик по ADR; финальные формулировки интегратор правит после слияния).

## Задачи

1. **Права.** Сверь `deploy/helm/kubron/**` и `internal/diagnose.AllowedKinds()` + `internal/opsplatform/allowlist.go`: каждый вид из `allowedReads` есть в RBAC (`get`, `list`) и в allowlist платформы; недостающее добавь. Опиши последствия отсутствия права (`Unknown/forbidden` + `MissingContext`, а не ошибка).
2. **Документация.** По разделам ADR: что умеет диагностика по каждому виду (Ingress, HPA, ConfigMap, StatefulSet, Job, CronJob), как читать цепочку и карту, какие сигналы добавляют метрики (необязательны; ingress-метрики — только при `ingress-nginx`), что делает «пересчитать корреляцию» (не обновляет Events), что **не** читается (Secret, содержимое ConfigMap, логи не сохраняются без согласия), лимиты графа.
3. **Развёртывание.** `docs/deploy.md`: новые виды в RBAC, влияние на число запросов, ограничения namespace-scoping.
4. **CHANGELOG и ADR.** Подготовь заготовку; статус этапов в ADR.
5. **Ссылки.** Проверь, что внутренние ссылки в документах существуют (скрипт или `grep`), а упоминаний удалённых промптов первой итерации (`docs/prompts/contracts.md` первой итерации) нет — теперь `docs/intelligence-contracts.md`.
