# D7 — Интерактивная карта зависимостей (ADR-0031 §8)

Перед началом прочитай `00-common.md`, `README.md` и `contracts.md` (§1 (формы вершин) и §6). Ветка: `intel2/d7-dependency-map` от `refactor`. Ты **ни от кого не зависишь** и никого не ждёшь: все точки расширения уже в `refactor`, чужие результаты берёшь из `contracts.md` и подменяешь фейками.

## Цель

Интерактивная карта зависимостей расследования: показывает граф отчёта (вершины по состоянию, типизированные рёбра, `Missing` и `Unknown` различимы, кандидат первопричины и цепочки подсвечены). Работает с **любым** графом отчёта: новые виды данных появятся сами.

## Твои файлы (создаёшь и правишь только их)

- `frontend/src/components/incidents/map/**` — `DependencyMap.vue` (вход: `report`, `selected`, событие `select`), `MapNode.vue`, `MapEdge.vue`, `MapLegend.vue`, `MapDetails.vue` и тесты рядом.
- `frontend/src/composables/dependencyMap.ts`, `dependencyMapLayout.ts` (+ тесты) — чистые функции: нормализация `Report.graph`, раскладка (слои по рёбрам `owns/routes/scales/selects`), фильтры, цепочки.
- `frontend/src/components/incidents/__fixtures__/map/*.json` — отчёты с графом разных форм (по `contracts.md` §1: Ingress, HPA, ConfigMap, StatefulSet, Job/CronJob, усечённый граф).
- `frontend/src/i18n/locales/{en,ru,cn}/incidentsMap.json` — все тексты карты.

## Не трогай

- `IncidentView.vue`, `ChainView.vue` и остальные существующие компоненты: встраивание — **одна строка D8** по контракту `DependencyMap` (пропсы `report`, `selected`, событие `select`).
- `frontend/src/composables/incidentModel.ts`, `types/incident.ts` (типы бери из него; нужных полей нет — опиши в PR).
- Бэкенд.

## Задачи

1. **Модель.** Чистая функция `buildMapModel(report)` → узлы/рёбра/слои; Secret-вершины (`Unknown/policy`) и заглушки `Missing` рисуются по-разному, не только цветом (форма/иконка/подпись — доступность).
2. **Раскладка.** Детерминированная слоистая раскладка без новых зависимостей (SVG; если нужна графовая библиотека — только уже установленная в `package.json`); устойчива к 1 000 вершин (лимит графа) — большие графы свёртываются по виду с раскрытием.
3. **Интерактивность.** Выбор вершины → `MapDetails` (факты и гипотезы по ресурсу, состояние, причина `Unknown`); подсветка цепочки до кандидата первопричины; фильтры по виду и состоянию; масштаб и сдвиг; клавиатурная навигация (стрелки, Enter, Esc), `role`/`aria-*`; уважай `prefers-reduced-motion` и тёмную тему проекта.
4. **Пограничные случаи.** Граф пуст/отсутствует (старый отчёт) — карта скрыта без ошибки; `partial`/усечён — явная пометка «граф неполный»; неизвестный вид ресурса — нейтральная вершина, не падение.
5. **Тексты.** Только через `$t('incidentsMap.*')`; коды фактов — через `codeText()` (безопасный текст при неизвестном коде, «сырые» коды не показываем).
6. **Безопасность.** Имена ресурсов выводятся как текст (без `v-html`); ничего не логируется.

## Тесты и фикстуры

Vitest: `buildMapModel` на фикстурах всех форм, раскладка детерминирована (снимок), клавиатура, пустой/усечённый граф, неизвестный вид. Проверь параметры `npm run i18n:check`. Компонентные тесты монтируют `DependencyMap` с фикстурами (не через `IncidentView`).

## Не входит

Встраивание в `IncidentView` (D8), живое обновление графа (отклонено ADR-0031 §8), редактирование графа.
